# ArcaneBet — Demo (fiktive Wettplattform)

Kurzanleitung
- Öffne die Datei [index.html](index.html) im Browser.
- Nutze die Simulation (Start/Pause) und passe die `Geschwindigkeit` an.
- Klicke auf Quoten, um Wetten zum Wettschein hinzuzufügen, setze einen `Stake` und klicke `Setze jetzt`.

Was die Demo macht
- Professionelles, dunkles Design mit goldenen Akzenten für ein exklusives Gefühl.
- Interaktive Matches (Fußball, Basketball, Tennis) mit Countdown, Live-Status und zufälligen Ergebnissen basierend auf Quoten.
- Wettschein, Einsatzverwaltung, einfache Abrechnung (Simulation; keine echten Zahlungen).

Dateien
- [index.html](index.html) — Hauptseite
- [styles.css](styles.css) — Layout & Styling
- [app.js](app.js) — Simulation & Logik

Entwicklungs-Hinweis
- Diese Demo ist für Demonstrationszwecke; keine Verbindung zu echten Wettanbietern.
